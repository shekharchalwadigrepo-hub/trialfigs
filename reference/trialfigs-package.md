# Efficacy and safety graphics for clinical review packages

Simulated-data utilities and submission-style figures commonly used in
clinical review packages. Not an FDA product. See
[`ta_plot_catalog`](https://shekharchalwadigrepo-hub.github.io/trialfigs/reference/ta_plot_catalog.md)
for the therapeutic-area map.
