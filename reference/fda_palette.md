# Color palette for review figures

Named colors for treatment arms and RECIST responses.

## Usage

``` r
fda_palette()
```

## Value

A named character vector of colors.

## Examples

``` r
fda_palette()
#>  Investigational          Control          Placebo Standard of care 
#>        "#1B4F72"        "#B9770E"        "#5D6D7E"        "#1A5276" 
#>               CR               PR               SD               PD 
#>        "#196F3D"        "#1A5276"        "#B7950B"        "#922B21" 
#>               NE        Responder    Non-responder 
#>        "#7F8C8D"        "#196F3D"        "#7F8C8D" 
```
